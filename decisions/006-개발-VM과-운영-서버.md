# 006. 개발 VM은 최소 사양, 운영 서버는 같은 구성

- 상태: 채택
- 날짜: 2026-11-02

## 배경

[ADR 005](005-실습-환경-실행-기반.md)는 개발 VM을 6 vCPU / 12GB / 80GB로 정했다. 그 뒤 운영 서버가 따로 있다는 점을 반영해야 했다. 운영 서버는 하드웨어만 있고 OS와 Kubernetes는 아직 설치하지 않았으며, 정확한 사양도 확인하지 못했다.

Sysbox 조건(Ubuntu, Kubernetes 1.32~1.35, containerd 2.0.5 이상)은 개발 VM과 운영 서버에 똑같이 걸린다.

## 선택지

1. 개발 VM은 최소 사양으로 두고, 운영 서버를 ADR 005와 같은 구성으로 설치
2. 개발 VM을 ADR 005 사양(6 vCPU / 12GB)으로 두고, 학습자 5명 규모 테스트도 개발 VM에서 함

## 결정

1번을 택한다. ADR 005에서 VM 사양만 바꾸고 나머지는 그대로 둔다.

- 개발 VM: 2 vCPU / 4GB / 40GB. 기능 동작만 확인하고 실습 환경은 1~2개만 띄움
- 운영 서버: 실제 서버에 Ubuntu Server 24.04, kubeadm 1.35, containerd 2.0.5 이상, Sysbox, Calico 설치. 개발 VM과 같은 구성
- 미정(결정 필요): 운영 서버 사양. CPU, RAM, 디스크를 확인해 이 ADR의 결과에 적는다

## 이유

- 2 vCPU는 kubeadm preflight check 최소값. 4GB는 control plane과 Calico(약 1.5~2GB 추정)에 실습 환경 1개(약 1GB 추정)를 더한 값이고, 모자라면 VM RAM만 늘리면 됨
- Sysbox 권장치(노드당 4 CPU / 4GB)는 preflight check 항목이 아님
- 운영 서버를 같은 구성으로 두면 개발 VM에서 되던 게 운영에서도 됨. 구성이 다르면 Sysbox 조건을 두 번 맞춰야 함
- 성능과 생성 시간은 실제로 쓸 서버에서 재야 의미가 있음

## 결과

- product.md의 미정 항목인 환경 생성 시간 한도는 개발 VM이 아니라 운영 서버에서 잰다.
- 학습자 5명 동시 테스트도 운영 서버에서 한다.
- 개발 VM 메모리 추정값은 첫 실습 환경을 띄운 뒤 실측값으로 확인한다.
