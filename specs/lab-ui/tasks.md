# fe 실습·관리 화면 작업 목록

관련 이슈: #83 · 결정: [decisions/027](../../decisions/027-fe-실습-관리-화면.md), [decisions/029](../../decisions/029-원본-읽기와-수정-표시.md), [decisions/030](../../decisions/030-내-기록-분석.md), [decisions/016](../../decisions/016-fe-디자인-방향.md), [decisions/022](../../decisions/022-공격-대상과-웹-터미널-연결.md)~[decisions/026](../../decisions/026-관리와-기록.md)

학습자가 문제를 골라 실습을 시작하고, 공격·방어·검증을 하고, 지난 기록을 보는 화면과 관리자 세션 화면을 만든다. 홈과 문제 목록에 필요한 내 진행 상태 API를 백엔드에 더한다.

## 완료 기준

- 문제 목록에서 검색·필터(분류, 난이도, 내 상태)·정렬·페이지로 문제를 찾고, 상세에서 실습을 시작함
- 실습 화면: 준비 단계 → 공격 대상과 터미널로 공격 → 공격 검증·힌트·건너뛰기 → 코드 수정·재배포·초기화 → 방어 검증·해답 → 완료 안내. 자동 종료 경고와 [계속하기], 종료 사유 안내(학습자, 입력 없음, 환경 이상, 관리자)
- 홈: 진행 중인 실습, 끝내지 못한 문제, 새로 추가된 문제, 분류별 진행, 최근 기록
- 내 실습 기록: 세션 목록과 세션 하나의 기록(상태, 검증, 재배포, 힌트, 연 해답), [분석] 탭(분류별 공격·방어, 강점과 보완할 점, 추천 문제, 활동)
- 관리자: 세션 목록(진행 중, 전체), 강제 종료, 세션 하나의 기록
- 라이트·다크 모두 `DESIGN.md` 규칙과 캡처를 따름. 모든 화면을 mock 모드로 확인할 수 있음

## 예외 상황

- 진행 중 세션이 있는데 다른 문제 시작: 진행 중 실습으로 안내
- 정원 초과, 승인 대기, 생성 실패: 각 안내와 다시 시작
- 터미널 연결 끊김: 이유 표시와 다시 연결(새 셸)
- 공격 대상 응답 없음이나 서비스 기동 중: 안내
- 검증·재배포·초기화 중 다른 작업 요청: 버튼 잠금, 409면 안내
- 저장 충돌(파일이 바뀜): 다시 불러오기 또는 덮어쓰기
- 마지막 재배포 뒤 저장한 파일이 있는데 방어 검증: "재배포하지 않은 변경이 있어요" 안내
- 세션이 끝났는데 실습 화면에 있음: 종료 사유와 문제 목록·기록으로 가는 길
- 관리자 아님: 관리자 화면 403
