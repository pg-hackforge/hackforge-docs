# 실습 세션 운영 관리 작업 목록

관련 이슈: #94 · 결정: [decisions/033](../../decisions/033-실습-세션-운영-관리.md), [decisions/026](../../decisions/026-관리와-기록.md), [decisions/022](../../decisions/022-공격-대상과-웹-터미널-연결.md), [decisions/024](../../decisions/024-방어-IDE-재배포-초기화.md)

관리자가 여러 세션을 한 번에 끝내고, 끝낸 이유를 학습자에게 알리고, 진행 중 세션을 읽기 전용으로 본다. 터미널 실시간 보기와 조작은 학습자가 수락했을 때만 한다. 공지·점검(#95)의 점검 자동 종료가 이 일괄 종료를 쓰므로 먼저 한다.

## 완료 기준

- 관리자가 고른 세션 또는 진행 중 전체를 한 번에 종료하고, 대상 중 종료 중·끝난 수로 진행 상황을 봄
- 종료 안내 문구가 학습자 실습 화면, 내 실습 기록, 관리자 세션 기록에 보임
- 관리자가 진행 중 세션의 단계, 파일과 수정한 줄, 빌드 로그, 검증 결과를 읽기 전용으로 보고, 열람이 내 실습 기록에 남음
- 터미널 보기와 조작은 요청 → 학습자 수락 뒤에만 되고, 허락된 동안 학습자 화면에 표시와 [그만 보게 하기]가 있음
- 조작 허락 동안 관리자가 자기 셸, 파일 저장, 재배포, 초기화, 공격 대상을 씀. 재배포·초기화 기록에 요청한 관리자가 남음
- 조작 허락이 처음 시작된 뒤의 검증에 "관리자 조작 뒤"가 보이고 분석 점수에는 포함됨
- 요청, 수락, 거절, 만료, 끝이 시각과 함께 내 실습 기록과 관리자 세션 기록에 보임

## 예외 상황

- 관리자가 아닌 사용자의 관리자 API: 403
- 일괄 종료 대상에 이미 끝난 세션: 건너뛰고 건너뛴 수를 줌
- 같은 세션에 열린 요청이나 허락이 있는데 또 요청: 409(터미널 보기 허락 중 조작 요청은 받음)
- 2분 안에 답이 없는 요청: 만료. 만료 뒤 수락: 409
- 학습자가 아닌 사용자의 수락·거절·그만 보게 하기: 404
- 허락이 끝나거나 세션이 `READY`가 아니게 됨: 관리자 터미널 보기와 관리자 셸을 서버가 닫음
- 허락 없는 관리자의 터미널 보기, 셸, 파일 저장, 재배포, 초기화, 공격 대상: 403
- 관리자 조작 중에도 검증 실행, 힌트, 건너뛰기, 해답 열기는 학습자만: 관리자 요청은 403
