# 계정 화면 작업 목록

관련 이슈: #53 · 결정: [decisions/011](../../decisions/011-계정-규칙.md), [decisions/018](../../decisions/018-계정-화면.md)

hackforge-fe에 로그인, 회원가입, 내 정보, 관리자 회원 관리 화면을 만든다. 화면 문구는 [ADR 019](../../decisions/019-화면-문구-말투와-용어.md)를 따른다. 백엔드 API(`openapi.yaml` 0.2.1)는 바꾸지 않는다. 시안을 먼저 그려 사람이 확정한 뒤 구현하고, fe PR은 확인할 화면 목록과 실행 방법을 적는다.

## 완료 기준

- 회원가입하면 바로 로그인되어 홈에 승인 대기 안내 띠가 보임
- 로그인하면 원래 가려던 화면으로, 없으면 홈으로 이동. 로그인한 상태로 `/login`, `/signup`에 오면 홈으로
- 내 정보(`/account`)에서 내 정보를 보고 비밀번호를 바꿈. 바꾸면 다른 기기의 로그인이 끝난다고 안내
- 관리자가 회원 관리(`/admin`)에서 상태별(승인 대기, 승인 완료, 거절) 목록을 보고 승인, 거절, 역할 변경, 임시 비밀번호 발급을 함
- 가입 화면에 개인정보 수집·이용 동의 문구(ADR 018)
- 모든 화면의 상태를 `npm run dev:mock`으로 볼 수 있고, 개발 백엔드로도 확인함

## 예외 상황

- 이메일이나 비밀번호가 틀림(401 `INVALID_CREDENTIALS`): 어느 쪽인지 구분하지 않는 한 문구
- 5번 연속 실패해 잠김(429 `ACCOUNT_LOCKED`): 15분 뒤 다시 시도하라고 안내
- 이메일·닉네임 중복(409 `EMAIL_TAKEN`, `NICKNAME_TAKEN`), 입력 규칙 위반(400 `VALIDATION_FAILED`): 해당 입력 칸 아래에 표시
- 가입은 됐는데 이어서 하는 로그인이 실패함: 로그인 화면으로 보내고 "회원가입이 완료됐어요. 로그인해 주세요"
- 비밀번호 변경에서 현재 비밀번호가 틀림(400 `CURRENT_PASSWORD_MISMATCH`): 현재 비밀번호 칸 아래에. 5번째로 틀려 잠기면 세션이 모두 지워져 로그아웃되고 로그인 화면에 잠금 안내
- 관리자가 자기 역할을 바꾸려 함: 화면에서 막음(백엔드도 403 `CANNOT_CHANGE_OWN_ROLE`)
- 다른 관리자가 먼저 처리해 상태 전이가 맞지 않음(409 `INVALID_STATUS_TRANSITION`): 안내하고 목록을 새로 고침
- 임시 비밀번호 창을 닫음: 다시 볼 수 없다고 미리 알림. 필요하면 다시 발급
