# 소개 화면 작업 목록

관련 이슈: 없음(작업 목록만으로 진행, 2026-11-25 사람이 결정) · 결정: [decisions/016](../../decisions/016-fe-디자인-방향.md), [decisions/017](../../decisions/017-기본-테마-다크.md)

로그인하지 않은 사람이 `/`에 오면 보는 소개 화면을 만든다. 디자인은 2026-11-18에 확정했다(ADR 016, hackforge-fe `DESIGN.md` "소개 화면"과 "소개 화면 효과", 확정 캡처 `design/screens/landing-*`, 시안 `.impeccable/mocks/decision/landing/`). 지금은 자리 표시 화면이 있다.

## 완료 기준

- 구간 순서: 첫 화면, 미리 보기, 실습 방식, 검증, 실습 환경, 문제, 마무리, 쇳물 글자, 맨 아래 줄. 내용과 배치는 확정 캡처를 따름
- 반응형: 1024px 이하에서 상단 메뉴를 숨기고 여러 열을 세로로 쌓음, 640px 이하에서 버튼 폭 가득과 양옆 여백 16px
- 효과는 `DESIGN.md` "소개 화면 효과" 표대로. 처음 한 번 재생되거나 스크롤에 맞춰 움직이고, 계속 반복하는 것은 미리 보기와 판정 카드뿐
- 맨 아래 줄에 개발자 이름과 연락처, HTML `meta author`(ADR 016, 2026-11-25 사람이 다시 확인)
- 라이트·다크 모두 확정 캡처와 같음. PR에 캡처(데스크톱과 휴대폰 폭)

## 예외 상황

- 로그인한 상태로 `/`에 오면 지금처럼 홈
- 움직임 줄이기(`prefers-reduced-motion`)를 켠 사람: 효과 없이 마지막 상태로 보여 줌
- 화면 밖에 있는 반복 효과(미리 보기, 판정 카드, 불티, 연기)는 멈춰서 기기를 덜 씀
- 스크립트 효과가 실패해도 글과 버튼은 보이고 누를 수 있음
- 실제 문제의 공격 문자열이나 해답을 쓰지 않음. 공격 입력은 가린 글자로만(ADR 016)
